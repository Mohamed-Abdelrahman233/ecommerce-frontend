# Ecommerce Frontend

A responsive e-commerce storefront built with **React**, **Vite**, and **React Router**.

## Features

- Product browsing, search, categories, and details
- Shopping cart and wishlist with localStorage
- Login, About, Blog, Contact, and Accessories pages
- Responsive design with page transition animations

## Tech Stack

React 19 · Vite 8 · React Router 7 · Swiper · Framer Motion · React Icons

## Run

```bash
npm install
npm run dev
```
